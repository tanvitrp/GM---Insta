# GM Insta – Mini Social Media Platform

GM Insta is a mini social media web application developed to provide users with a simple platform to connect and share content. The project demonstrates essential web development concepts, including user authentication, session management, database connectivity, and interactive user interfaces.

## 🚀 Features

* **User Authentication:** Supports user registration and login.
* **Session Management:** Maintains user sessions.
* **Post Management:** Provides social media post-related functionality.
* **Interactive Interface:** Uses EJS templates, HTML, CSS, and JavaScript to create dynamic web pages.
* **Database Integration:** Uses MongoDB with Mongoose for data management.
* **Password Security:** Uses bcryptjs for password hashing.
* **File Upload Support:** Uses Multer to handle file uploads.

## ⚙️ Installation and Setup

### Prerequisites

Install the following before running the application:

* Node.js and npm
* MongoDB, or access to a configured MongoDB database
* Git (optional, for cloning the repository)

### Step 1: Clone the Repository

```bash
git clone https://github.com/tanvitrp/GM---Insta.git
```

### Step 2: Navigate to the Project Directory

```bash
cd GM---Insta
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Configure the Database

Ensure MongoDB is running and configure the database connection according to the settings in `app.js`.

Do not upload database credentials, passwords, or other sensitive configuration details to GitHub.

### Step 5: Start the Application

```bash
npm start
```

The application starts using the command configured in `package.json`.

Open the local address specified in the terminal or application configuration to access the website.
